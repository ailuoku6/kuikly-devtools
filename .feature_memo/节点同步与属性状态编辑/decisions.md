# 决策

## 2026-09-24

- 用原始 e 类型信息决定可写性和颜色回写类型，避免把 0x 字符串写到 Kuikly 的 Color/Int 中。
- 服务端做颜色解析/规范化，runtime 只做最终 Kotlin 类型构建；CSS rgba 仅在浏览器渲染色块时产生。
- 全量截图树不等于真实变化，拆开发送数量与实际变化数量。
- 编辑通过已有 HTTP ingest 轮询下发，以 requestId 回执明确区分排队成功与执行成功。
- 复杂对象/集合与不可无损编码值只读，避免把展示用字符串反写回业务对象。
- Gradle 标准构建被沙箱/自动审批服务 503 阻断；采用仅写临时目录的编译测试路径，读取已有依赖，不修改全局缓存。本地 fat JAR 复用依赖并更新已测试的编译类。

## 2026-09-25

- 上传成功回调增加截图调度，而非减少状态订阅频次；保留已有实时状态信息与截图速率限制。
- AI 编辑复用已有 WebSocket 命令/回执，无新增服务端结果缓存或长轮询 HTTP 接口；唯一 requestId 区分并发修改。
- 编辑提示由可写类型 e 推导，不编造未在 runtime/server 定义的原生字符串枚举。
