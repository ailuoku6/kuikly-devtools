# 需求

- 截图发送到 server 的同一请求附上最新节点树。
- devtools 面板编辑节点属性、组件 view/attr 状态并获得设备结果。
- 移除页面侧颜色显示转换；server 负责展示规范化与按原始类型回写。

## 范围

- 支持已有渲染属性、尺寸、margin/padding、flex、布局枚举，以及基础类型/Color 的 mutable state。
- val、复杂对象/集合、未初始化或不可无损传输的字段保持只读；不修改业务源码。
- 不新增任意 Kotlin 表达式执行、不实现复杂对象反序列化。
- 截图异步完成，树在上传时采集，不承诺像素级原子一致性。
